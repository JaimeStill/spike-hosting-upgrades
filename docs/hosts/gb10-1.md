# gb10-1

The first GB10 workstation's host descriptor, read by the hosting-upgrades skill
(`.claude/skills/hosting-upgrades/`). It records only what the skill needs to reach the host and
judge what it finds there; every other fact (its hardware, OS, kernel, engines, served and stored
models) comes from the probe a run takes. gb10-2 has no descriptor: it is reserved for
spike-ai-pipeline.

## SSH short name

`gb10-1`

## Purposes

The model purposes the host is meant to serve: model set A's roles, which spike-model-engines
measured on this host class (`ai-hosting.md`, "Answer · experiment.hosting.spike-model-engines").

- **agent**: the main chat and tool-calling model the consumers' agent sessions run on.
- **vision**: image input beside text.
- **audio**: speech and audio input beside text.
- **embedding**: text embeddings for retrieval.

## Watch items

Named things every run checks, beside its own scan.

- vLLM NVFP4 decode speed on SM121
- EmbeddingGemma 2 serving on SM121
- llama.cpp concurrent-session throughput

## Measurements

The workspace's own dated findings on this host, which a run counts as attributed benchmarks on
it. None.
